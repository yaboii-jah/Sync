# Original Sync design lock

All platform, attendee, organizer, and super-admin screens share the original Sync identity. This is a restoration, not a new navigation or layout system.

- Canonical palette: `app/globals.css`; dark teal surfaces, gold primary actions, green success, blue keyboard focus, warm red errors.
- Platform aliases: `tokens.css`; no light or event-dependent overrides.
- Typography: Geist for interface text; Perandory for the Sync wordmark.
- Landing: existing sky artwork, original hero atmosphere and centered Sync identity, generic event copy.
- Layout: preserve the event index, mobile attendee navigation, and organizer workspace.
- Controls: at least 44px high, explicit loading/error/success states, keyboard focus, reduced-motion support.
- Event identity: logos and covers are content, never interface color or font sources. Stored theme fields are compatibility-only.

Hallmark review follows the user-approved original system; catalog diversification is intentionally inapplicable to this restoration.
